# LOLA Launchers

Keep this folder clean—use the two native Windows shortcuts below (no `.bat` terminal popups):

- **`Play LOLA.lnk`** — Starts the LOLA game directly (uses `--safe-mode` software renderer so there is no black screen and no console window).
- **`LOLA Developer Workbench.lnk`** — Opens the standalone LOLA Image & Story Developer Workbench (`lola_image_workbench.exe`).

## Subfolder: `tools/`
Contains developer, testing, and legacy scripts (`game_launcher.pyw`, `game_launcher_core.py`, `Lint LOLA.bat`, `Build Image Workbench Release.bat`, `Launch Image Workbench.bat`, `Play LOLA.bat`, `Play LOLA Direct.bat`).
