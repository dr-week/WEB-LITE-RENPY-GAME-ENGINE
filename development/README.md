# Game development tools

Launchers are organized in [../launcher/](../launcher/), with player game launchers separated from developer tools:

- **Image Workbench:** double-click [../launcher/tools/Launch Image Workbench.bat](../launcher/tools/Launch%20Image%20Workbench.bat)
  to open the native artwork workflow. See [image-workbench/README.md](./image-workbench/README.md).
- **Play LOLA (Player Launcher):** double-click [../launcher/Play LOLA.bat](../launcher/Play%20LOLA.bat).
- See [../launcher/README.md](../launcher/README.md) for direct launch, lint, and release build details.
